## Принципы
- queue.db на relay НЕ шифрована намеренно: только E2E-конверты + публичные ключи, красть нечего.
- Анти-replay — окно seen_nonces в SQLCipher, привязка к пакету (n / auth_sig), не к факту сессии.
- Каждый тест — с положительным контролем: без него "отвергнуто" ничего не доказывает.
- Урок сессии: объединённый патч-скрипт, упавший на assert, может оставить ЧАСТЬ правок неприменёнными — проверять grep'ом ПЕРЕД записью "PASS".
